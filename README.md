## What is Qwnks' Console Experience: Refreshed
Qwnks Console Experience: Refreshed aims to enhance Minecraft by changing World Generation, Adding New Structures, New Crops, Controller Support, & Many QoL Changes all while remaining Vanilla-ish, Lightweight, and Easy to Run!

## Built on Fabric & Neoforge!
Qwnks' Console Experience: Refeshed is built on Fabric and Neoforge meaning you don't have to swap from your favourite mod loader to play it!

## Runs on Sodium, Lithium, and More!
Qwnks' Console Experience: Refreshed uses Sodium, Lithium, and many more to help your game run it's best!
