# Security Policy

## Reporting a Vulnerability

If you discover a **security vulnerability**, please **do not** open a public issue. Instead, use the following **confidential contact methods**:

* **GitHub:** Click the [Security tab](https://github.com/Qwnks/Qwnks-Console-Experience/security), then [Report a vulnerability](https://github.com/Qwnks/Qwnks-Console-Experience/security/advisories/new) and fill out the advisory details form.
